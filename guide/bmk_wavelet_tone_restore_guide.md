# BMK Wavelet Tone Restore — 핵심 가이드

디테일러(타일 부분 디노이즈) 업스케일 결과에 **원본의 저주파 계조·색 분포를 이식**하여,
업스케일 과정에서 밍숭맹숭해진 대규모 명암(구름 그라데이션, 전역 톤)을 복원하는
후처리 노드입니다. 기존 **ColorMatch(Reinhard) 단계를 대체**합니다.

---

## 왜 필요한가

denoise 0.35~0.5 타일 재샘플링은 고주파 디테일을 늘리는 대신, 모델 prior 의 평균
회귀로 저·중주파 계조를 중간톤 쪽으로 수축시킵니다. 각 타일이 이미지 전체의 조명
구배를 볼 수 없어 타일 로컬 통계로 톤이 재정규화되는 효과도 겹칩니다.

Reinhard ColorMatch 는 전역 평균/표준편차만 원본에 맞추는 연산이라 이 손실을
**전역 스트레치로 가릴 뿐**이며, 그 과정에서 이미 좁게 수축된 하이라이트 클러스터가
255 밖으로 밀려 클리핑됩니다 (업스케일본 히스토그램 우측 끝의 수직 스파이크가 그
흔적). 결과: 통계는 맞아 보이는데 계조는 사라진 상태.

## 원리 — 주파수 분리 합성

    출력 = image 의 고주파      (디테일러가 새로 만든 선명한 디테일)
         + reference 의 저주파  (원본의 톤·색·대규모 그라데이션)

수식으로는 단일 항등식입니다: `out = image + strength × (low(reference) − low(image))`

저주파 정보는 원본에 온전히 존재하고 bicubic 확대로도 사실상 손실 없이 전달되므로,
"타일 디노이즈로 인한 저주파 계조 손실"이라는 문제에 대해서는 실용적으로 완전한
복원입니다. 전역 스트레치가 없으므로 클리핑도 발생하지 않습니다.

구현은 StableSR 의 wavelet color fix 와 동일 계열로, 3×3 가우시안을
dilation = 1, 2, 4, …, 2^(levels−1) 로 반복 적용해 저주파를 분리합니다. 다단계
분해이기 때문에 단일 대형 블러 스왑 방식보다 고대비 경계의 헤일로가 크게 적습니다.

## 배선

    [원본 T2I 출력 (1248×1824)] ────────────────────────→ reference
    [업스케일 → Tile SEGS → Detailer → (VC Crop)] 최종 ─→ image
                                                          │
                                       [BMK Wavelet Tone Restore] → 최종 출력

- 기존 ColorMatch(Reinhard) 노드는 **제거**합니다 (이 노드가 색 매칭을 겸함).
- reference 해상도가 달라도 노드가 자동으로 bicubic 리사이즈합니다.
- virtual_canvas 파이프라인이라면 **BMK Virtual Canvas Crop (Restore) 이후**,
  즉 원본 좌표계로 복원된 이미지에 연결합니다.

## 파라미터

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `mode` | `rgb` | `rgb`: 색+계조 모두 이식 (ColorMatch 완전 대체). `luminance_only`: 휘도(Y, BT.709) 계조만 이식하고 색은 image(디테일러 결과)의 것을 유지 |
| `levels` | `0` (자동) | 저주파/고주파 컷오프. 자동 = round(log2(min(H,W)/16)): 512→5, 1024→6, 2048~2496→7, 4096→8. 클수록 더 미세한 구조까지 reference 톤이 지배 |
| `strength` | `1.0` | 저주파 이식 강도. 1.0 = 완전 이식, 0.0 = 통과. 1.0 초과는 외삽(원본보다 계조를 더 벌림) |

## levels 튜닝 — delta_preview 활용

`delta_preview` 출력(중간 회색 = 변화 없음, 밝음/어두움 = reference 가 더 밝음/어두움,
게인 4: ±0.125 → 흑~백)을 PreviewImage 에 연결해 확인하면서 조정합니다.

- 구름·하늘의 대규모 명암 구배가 프리뷰에 부드러운 밝기 얼룩으로 보이면 → 그
  대역이 이식되고 있다는 뜻. 정상.
- 프리뷰가 거의 균일한 회색이고 결과 톤 변화가 없다 → levels 가 너무 낮아 컷오프가
  좁음. 1~2 올림.
- 프리뷰에 캐릭터 윤곽선·머리카락 같은 미세 구조가 또렷하게 보인다 → levels 가
  너무 높아 디테일러가 개선한 중간 스케일까지 원본(저해상도) 쪽으로 되돌리는 중.
  1~2 내림.
- 2496×3648 기준 자동값 7 에서 시작, 구름 계조가 부족하면 8 을 시험.

콘솔 로그의 `저주파 Δ mean/max` 통계도 참고하세요. mean 이 0.01~0.05 수준이면
전형적인 복원량이고, 0에 가깝다면 이식할 차이가 없거나 levels 가 낮은 것입니다.

## ColorMatch(Reinhard) 와의 차이

Reinhard 는 전역 스칼라 2개(평균/표준편차)만 맞추는 통계 보정이라 공간 정보가 없고,
수축된 분포를 강제로 벌리는 과정에서 하이라이트 클리핑을 만듭니다. 이 노드는
공간적으로 변하는 저주파 필드를 통째로 이식하므로 "어디가 어둡고 어디가 밝았는지"가
그대로 복원되고, 값이 원본 근방을 벗어나지 않아 클리핑이 없습니다. 검증하려면
적용 후 히스토그램에서 우측 끝 스파이크가 사라졌는지 확인하세요.

## 설치

1. `bmk_wavelet_tone_restore.py` 를 `ComfyUI_BMK_Nodes/` 에 배치.
2. `__init__.py` 의 `_NODE_MODULES` 에 `"bmk_wavelet_tone_restore",` 추가
   (`bmk_upscale_with_model_tiled` 와 `bmk_wildcard_prompt` 사이, 알파벳 순).
3. ComfyUI 재시작 → `BMK/Image` 카테고리에서 "BMK Wavelet Tone Restore" 확인.

## 트러블슈팅

- **고대비 경계(실루엣 주변)에 옅은 헤일로**: levels 를 1 내리거나 strength 를
  0.8~0.9 로. 다단계 분해라 드물지만, 원본↔업스케일의 구조 차이가 큰 경우 발생 가능.
- **디테일러가 개선한 색감이 사라짐**: `mode=luminance_only` 로 전환 — 계조만
  복원하고 색은 유지.
- **GPU 메모리 부족**: 자동으로 CPU 폴백됨 (로그 확인). 2496×3648 기준 CPU 에서도
  수 초 내 처리.
- **결과가 원본과 너무 비슷해져 업스케일 의미가 없어 보임**: 정상 범위인지 확인 —
  이 노드는 저주파만 되돌리므로 100% 확대로 보면 고주파 디테일은 그대로여야 함.
  그렇지 않다면 levels 과대.
- **작은 이미지에서 levels 수동 과대 입력**: replicate 패딩 제약에 맞춰 자동
  클램프됨 (경고 로그 출력, 에러 없음).

## 한계

재샘플링 손실 자체를 없애는 것이 아니라 손실된 대역을 원본에서 복원하는
방식이므로, 컷오프 근처 중간 주파수 대역의 미묘한 계조는 절충됩니다. 상류에서
손실량 자체를 줄이려면 배경/하늘 위주 타일의 denoise 를 낮추는 세그먼트별
denoise 변조(BMKAnimaLLLiteSEGSHook 의 pre_ksample 확장)를 병행할 수 있습니다.

## 검증 이력 (v1)

numpy 기반 torch shim 위에서 모듈 코드를 무수정 실행하는 기능 테스트 21건 전부
통과: strength=0 항등성, YCbCr(BT.709) 왕복(오차 <1e-6), 계조 수축→복원 시나리오
(저주파 오차 0.1046→0.0018, 고주파 보존), luminance_only 크로마 보존(<1e-7),
reference 자동 리사이즈, 배치 정합, levels 자동 산정/클램프, 알파 통과,
출력 범위 [0,1].
