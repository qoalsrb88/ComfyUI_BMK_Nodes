            알아 둘 것

            • 보드는 선택만 기록합니다. 유료 호출은 ComfyUI 탭의 큐(승인 템플릿 또는 Review 노드 부분 실행)로만 일어납니다.
            • 선택은 저장되며, 유료 호출은 승인 후 서버가 실행합니다.
            • 다시 생성·승인은 아래 상태 줄 "ComfyUI 탭 연결"의 탭으로 갑니다 — Open Board 또는 메뉴 BMK → Design Patch Studio 로 연 탭, 또는 ComfyUI 탭이 하나뿐이면 채널로 찾은 탭(확장 새 판).
            • 다시 생성·승인은 이 프로젝트의 서버 작업으로 실행됩니다.
            • 승인 제출(초안·생성 승인, 그 탭으로 가는 다시 생성(R)·[다시 생성 보내기])은 ComfyUI 탭에 열린 그래프에서 실행마다 바뀌는 값을 한 번 진행시킵니다(그래프는 실행하지 않음) — 시드 제어(randomize·increment)와 Pixaroma Dropdown·Prompt 의 순서·무작위 선택이 다음 값으로 넘어가고(Prompt 순서는 설정에 저장됨), BMK Cyclic Seed 의 batch_count 를 1 로·자동 난수를 새로 뽑으며, 워크플로가 '수정됨'이 되고, 이 실행이 그 워크플로의 실행으로 큐·진행 표시에 보입니다.
            • 초안·생성 승인은 확인한 계획에만 적용됩니다. 작업이 바뀌면 계획을 다시 확인하고 승인하세요.
            • ComfyUI 의 Cancel 은 진행 중인 유료 호출을 버립니다(돈을 내고 결과를 못 받음). 멈추려면 새 호출 멈춤 을 쓰세요.
            • 진행 중인 호출의 결과까지 받으려면 새 호출 멈춤을 쓰세요.
