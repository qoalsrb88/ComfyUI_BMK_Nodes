          설정실행 설정(pipeline.json — 노드 위젯 그대로). "확인 필요"가 남으면 반영·Export 를 막음(추정한 Prepare 설정으로 셀이 뒤집히지 않게)
          반영 · Export무료 템플릿(Run·Spec Draft 없음)을 ComfyUI 에 직접 큐 — 탭 불필요. 반영 = Import → Prepare → Analyze → Review(대기열 앞), Export = Analyze → Compose → Export(대기열 뒤)
          계획Run·초안의 승인 필요 수·비용·해시(노드와 같은 계산). [초안 승인]·[Run 승인] = 확인 창 뒤 ComfyUI 탭이 서버 템플릿을 큐에 넣음(유료 승인을 받는 탭 — 상단 "ComfyUI 탭 연결"), wave 로 멈추면 [남은 N건 이어서 승인]. 해시 복사는 그래프 노드의 approve·only 에
          채택 · 수정 · 해제스펙 _layer_targets 를 씀(미리보기 → 확인). 반영은 다음 무료 반영

          진행 모드에서는 검토 키(Space·X·R·Q·D·C·S·M·V·화살표)와 E·T 가 꺼집니다. 재굴림(R)·ComfyUI 큐는 유료 승인을 받는 탭이고 서버가 템플릿을 낼 수 있으면 재굴림 템플릿(사전 승인 재굴림·복구만 과금), 그 길이 막히면(옛 확장·탭이 큐 처리 중·실행 설정 미저장·확인 필요·경로 경고·옛 서버) Open Board 탭의 Review 부분 실행입니다(지금 보내는 큐는 사용자 키·클릭만 — 스크립트 R 은 예약만).

          알아 둘 것

          • 보드는 선택만 기록합니다. 유료 호출은 ComfyUI 탭의 큐(승인 템플릿 또는 Review 노드 부분 실행)로만 일어납니다.
          • 재굴림·승인은 상단 "ComfyUI 탭 연결"의 탭으로 갑니다 — Review 노드 Open Board 로 연 탭, 또는 ComfyUI 탭이 하나뿐이면 채널로 찾은 탭(확장 새 판).
          • 승인 제출(초안·Run 승인, 그 탭으로 가는 재굴림·ComfyUI 큐)은 ComfyUI 탭에 열린 그래프에서 실행마다 바뀌는 값을 한 번 진행시킵니다(그래프는 실행하지 않음) — 시드 제어(randomize·increment)와 Pixaroma Dropdown·Prompt 의 순서·무작위 선택이 다음 값으로 넘어가고(Prompt 순서는 설정에 저장됨), BMK Cyclic Seed 의 batch_count 를 1 로·자동 난수를 새로 뽑으며, 워크플로가 '수정됨'이 되고, 이 실행이 그 워크플로의 실행으로 큐·진행 표시에 보입니다.
          • ComfyUI 의 Cancel 은 진행 중인 유료 호출을 버립니다(돈을 내고 결과를 못 받음). 멈추려면 Drain 을 쓰세요.
          • MOCK 배지 = 과금 없는 mock 백엔드 결과입니다.
          • 썸네일은 크롭 해상도(최종 PSD 에서 보이는 크기)로 배치·정합·톤 보정한 모습을 초점 박스로 확대한 것입니다. 판정은 캔버스의 1:1 로.
          • ★ 합성은 Compose 와 같은 계산(마지막 Export 설정)입니다. 분석 없는 ★ 은 마스크 없이 합성됩니다 — Analyze 뒤에 다시 보세요.
          • 여러 타깃을 한 번에 고친 결과(공동)는 첫 타깃(보통 A)에만 ★ 하세요. 같은 이미지를 여러 타깃에 ★ 하면 "중복 ★" 경고가 뜹니다.
          • "옛 크롭" = 크롭 사각형을 옮기기 전에 만든 후보입니다. ★ 하면 그때 크롭 크기 그대로 붙습니다.
